# Quote Reply

Ответы на выделенные фрагменты сообщений BB. Агент получает полный текст цитаты, ответ и идентификатор исходного сообщения; в интерфейсе несколько ответов объединены в бейдж «N цитат».

## На компьютере

1. Выделите текст и выберите «Ответить». Меню также содержит «В боковой чат» и «Цитировать» — штатное добавление цитаты BB.
2. Напишите ответ в окне рядом с выделением. Поле растёт до восьми строк, затем прокручивается. У нижней границы области ввода окно растёт вверх.
3. Кнопка добавления или `Enter` сохраняет ответ в черновик. `Shift Enter` переносит строку. `⌘ Enter` или `Ctrl Enter` отправляет только ответ на цитату, сохраняя основной черновик.

Кнопка «Ответить» под сообщением цитирует сообщение целиком.

## На телефоне

Совместно с BB Mobile панель ответа появляется после снятия системного выделения. Кнопка «Ответить» открывает поле внизу вместо обычного поля ввода. Клавиатура появляется только по тапу в текст; микрофон доступен сразу.

Поле остаётся открытым при касаниях переписки и скрытии клавиатуры. `Enter` переносит строку. Кнопка добавления сохраняет цитату в черновик; крестик закрывает редактор. Набранный ответ остаётся в памяти до открытия другой цитаты или перезагрузки страницы.

Микрофон использует настройки записи и распознавания BB. «Стоп» добавляет расшифровку в текст для проверки и редактирования. Во время записи и распознавания отправка заблокирована; явное закрытие прекращает работу редактора.

## Просмотр и хранение цитат

Наведите курсор на бейдж «N цитат» или нажмите его. Список показывает исходный фрагмент и ответ; в черновике доступны редактирование, удаление одной цитаты и удаление всех. В отправленных сообщениях список доступен только для просмотра.

Каждое сохранение создаёт неизменяемую запись в KV-хранилище плагина. Редактирование сохраняет старые версии для очереди и истории. Удаление из черновика убирает ссылку; автоматической очистки записей нет. Добавленные цитаты хранятся в черновике BB как plugin mentions.

При ошибке сохранения набранный текст остаётся в редакторе. Ошибки удаления и загрузки выводятся рядом с соответствующими действиями. Для раскрытия цитат агенту плагин должен быть включён; его хранилище нужно сохранять вместе с данными BB.

## Разработка и проверка

Требуются BB с Plugin SDK 0.6.104 или новее и совместимая с зависимостями версия Node.js.

```sh
npm ci --include=dev
npm run check
npm test
bb plugin build
bb plugin reload quote-reply
```

`server.ts` хранит ответы и раскрывает контекст. `app.tsx` управляет редактором и списком цитат. `mobile-reply.ts` принимает мобильное действие только при наличии подходящего собственного composer. `inline-cards.ts` скрывает стандартные плашки, сохраняя их содержимое под управлением BB. `sent-quotes.ts` объединяет плашки истории; наблюдатель общий для открытых композеров. `selection-menu.ts` задаёт визуальный порядок штатных кнопок через CSS.

## Ограничения

DOM-адаптеры зависят от разметки BB. При обновлении хоста нужно проверять меню выделения, плашки и основной/боковой чаты. Отключение плагина восстанавливает оформленные им элементы.

Цитата и ответ ограничены 40 000 символами каждый и суммарным размером сериализованной записи 256 KiB. При превышении размера интерфейс предлагает сократить текст.

Автотесты проверяют хранение, диапазоны упоминаний, ошибки, смену цитаты во время сохранения, привязки композеров и очистку адаптеров. Клавиатуру, системное меню и запись голоса проверяют на реальном телефоне: jsdom и видеоповтор с клавиатурой Mac эти переходы не воспроизводят.
