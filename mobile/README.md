# BB Mobile

Мобильные доработки штатного интерфейса BB. Плагин работает в веб-части приложения на iPhone, iPad и Android; на компьютере остаётся неактивным.

## Цитата после закрытия системного меню

1. Выдели фрагмент ответа. BB Mobile сохраняет текст и поле ввода исходного чата; веб-меню BB скрыто, пока активно системное выделение.
2. Закрой системное меню касанием вне выделения. После снятия выделения над полем ввода появляется панель с фрагментом цитаты, кнопкой «Ответить» и меню «⋯».
3. «Ответить» открывает редактор Quote Reply. В меню «⋯» доступны «В боковой чат», «Цитировать» и «Отменить».

Панель остаётся при касаниях переписки и вводе текста. Её закрывают выбранное действие, явная отмена или потеря исходного поля при навигации. Новое выделение в переписке заменяет сохранённый фрагмент.

Для ответа используется собственное поле Quote Reply, найденное по треду. При неоднозначном адресате плагин сохраняет возможность штатного действия BB. «Цитировать» добавляет обычную Markdown-цитату в черновик исходного чата.

Системное меню Apple остаётся штатным. Плагин реагирует на снятие выделения; браузерный JavaScript не сообщает достоверно о закрытии системного меню. Число необходимых касаний и показ клавиатуры нужно проверить на настоящем iPhone.

## Поле ввода и форматирование

Цитата привязана к конкретному полю ввода через публичный `useComposer()` и маркер внутри его окна. Основной и боковой чаты получают отдельные привязки. При закрытом или неоднозначном адресате вставка отменяется.

Форматирование восстанавливается из выделенного HTML через Turndown и GFM: ссылки, жирный текст, код, списки и таблицы. Частичные списки, таблицы и математические формулы могут отличаться от исходного Markdown. Снимок ограничен 32 000 символами, хранится в памяти страницы и добавляется только по нажатию кнопки.

После добавления цитаты плагин выбирает пустой абзац под блоком цитирования. Позиция повторно закрепляется после отложенного восстановления фокуса редактором. Следующий жест пользователя отменяет эту коррекцию.

## Разработка

```sh
npm install --include=dev
npm test
npm run typecheck
bb plugin build .
bb plugin install . --yes
```

`app.tsx` связывает штатные поля ввода с публичным composer API. `saved-quote.ts` сохраняет выделение и управляет панелью действий. `mobile.ts` отвечает за мобильную активацию и каретку. `bindings.ts` хранит живые привязки полей ввода.

Файлы приложения BB остаются исходными. При изменении разметки BB селекторы могут потребовать обновления. Отключение и перезагрузка плагина снимают слушатели, стили, временные наблюдатели и кнопки.
