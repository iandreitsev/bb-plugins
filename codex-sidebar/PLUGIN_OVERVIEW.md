# Codex Sidebar

Native BB thread rows organized into Pinned, Priority and calendar groups, with nested visible children and inline muted project names.

Priority remembers threads that started or failed, including activity while the list was closed. Clearing removes fully read, finished trees from Priority. Folded parents summarize descendant activity; navigating to a child reveals its ancestors.

A bell beside New thread and the command “Сайдбар: приоритет / по проектам” switch between this view and BB's standard list. Rows retain BB's thread menus, splits and numbered shortcuts, with a copy-link quick action and double-click rename.

See [README](README.md) for state, checks, upstream maintenance and large-list limitations.
