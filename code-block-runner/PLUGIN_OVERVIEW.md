# Code Block Runner

Кнопка ▶ в shell-блоках ответа запускает команды в папке и на машине треда. Статус, код завершения и вывод появляются под блоком, а результат автоматически получает агент этого же разговора.

Интерактивный ввод доступен через встроенный терминал. Фоновый монитор продолжает следить за выполнением после ухода из треда.

Поведение и ограничения описаны в [README](README.md).
