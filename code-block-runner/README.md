# Code Block Runner

Плагин добавляет кнопку ▶ к блокам `bash`, `sh`, `shell` и `zsh` в ответах агента. Нажатие сразу выполняет блок в терминале машины и рабочей папки исходного треда. Блок должен быть дописан до закрывающей ограды. Повторное нажатие во время работы останавливает процесс.

## Результат

Под блоком появляются статус, код завершения и последние 16 000 символов вывода. После завершения плагин отправляет команду, вывод и код завершения агенту того же треда скрытым вводом `agent-only`. Технический отчёт остаётся в контексте агента; в интерфейсе результат виден возле блока кода. Уведомление просит агента продолжить зависимую работу и отвечать по существу, без отдельного подтверждения успешного теста. Работающему агенту сообщение ставится в очередь, у свободного начинается новый ход. При ошибке доставки плагин повторяет отправку.

Монитор работает на стороне сервера: уход из треда и перезагрузка интерфейса сохраняют наблюдение. Состояние запусков хранится в KV плагина; сохраняются до 100 завершённых и доставленных запусков. При отключении плагина процесс терминала может продолжить работу, но монитор и доставка результата останавливаются до включения. ID терминала сохраняется до создания процесса: после потери ответа или сбоя записи плагин находит тот же терминал и продолжает наблюдение, сохраняя возможность остановки. Автоматически команда повторно не запускается.

## Интерактивные команды

Во время выполнения доступна кнопка «Открыть терминал» для ввода пароля, работы в редакторе или выхода из оболочки. Выполнение считается завершённым после выхода из процесса.

Блок исполняется как обычный shell-скрипт. В конструкции `ssh host` с отдельными командами на следующих строках эти команды исполнялись бы локально после завершения SSH. Такой простой неоднозначный блок плагин отклоняет до запуска; для удалённой последовательности используйте `ssh host 'команды'` или heredoc. Плагин сохраняет обычную семантику Bash, включая код завершения последней команды.

## Разработка

`npm test` проверяет запуск, завершение, скрытое уведомление агента, повторные клики, остановку и перезагрузку. Регрессионные сценарии воспроизводят потерю ответа создания терминала, сбой записи после создания процесса и запоздавшие ответы интерфейса после запуска или остановки. `npm run typecheck` проверяет типы. `bb plugin build` собирает плагин, `bb plugin install .` устанавливает его, `bb plugin reload code-block-runner` перезагружает.

Интеграция использует публичные API bb: renderer блока кода, терминалы, отправку сообщений и фоновый монитор. Штатный блок с подсветкой и копированием остаётся внутри компонента `Original`.
